# Security

Earthler has no published code and no version to install yet, so no version receives security fixes for now. This file will be updated when the first version exists.

## How to report

Do not open a public issue for a security problem. Use GitHub's private reporting: in the Security tab of this repository, choose Report a vulnerability. Only the project's maintainers can read the report.

Tell us what you found, how to reproduce it and what impact you see. We ask that you do not disclose the problem before a fix exists or before we agree on disclosure.

## What to expect

The project is maintained with no promise of support and no guaranteed response time, and it does not offer financial rewards. Anyone who reports a real problem gets credit in the fix, if they want it.

## Other private reports

Until the project has its own contact address, code of conduct reports use this same channel, with the word Conduct in the title.
