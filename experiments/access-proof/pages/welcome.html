Earthler access proof

This page checks whether a phone can reach a community server through the browser, with the community's own certificate and with no internet access. It is a test, not the Earthler system.

2. Install the certificate

The certificate only works for {{.Domain}} and for private network addresses. Remove it from this device when the test is over.

Download the certificate
iPhone or iPad
  1. Open this page in Safari, tap Download and allow the profile.
  2. Open Settings, tap Profile Downloaded and install it.
  3. Go to Settings, General, About, Certificate Trust Settings and turn on full trust for the Earthler access proof root.
Android
  1. Tap Download to save the file.
  2. Open Settings and search for CA certificate. It is usually under Security, Encryption and credentials, Install a certificate.
  3. Android shows a warning. Choose to install anyway and pick the downloaded file.
Computer
  1. Download the file and open it.
  2. Mark it as trusted for websites in the system certificate store. Firefox keeps its own list, under Settings, Certificates.

3. Open the secure site
